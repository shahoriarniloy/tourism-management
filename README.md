# 🧭 Tourism Management System

A modern web-based solution for seamless resort and destination bookings, guest management, and secure payments.

---

## ✨ Features

🔍 Search for resorts or destinations and 🏨 book rooms or packages by making secure 💳 payments.  
📖 View booking history, including details of past and upcoming 🗓️ reservations.  
🏝️ Manage resort details, including 🛏️ rooms and 🎁 package offerings.  
🧾 Oversee guest check-ins ✅ and check-outs 🚪.

---

## 🛠️ Tech Stack

- ⚛️ **Next.js** – React-based framework for fast and SEO-friendly interfaces  
- 🔐 **next-auth** – Secure authentication and session management  
- 🎨 **Tailwind CSS** – Utility-first CSS framework for responsive styling  
- 🛢️ **MongoDB** – NoSQL database for flexible and scalable data storage
